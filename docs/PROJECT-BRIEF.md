# Pipestry Project Brief

## Status

Early product-definition stage.

## Product

Pipestry is a new application inspired by the legacy Embers pipe and tobacco application. The new product will be defined intentionally rather than treated as a direct technical port of the legacy system.

## Known decisions

- Product/project name: **Pipestry**.
- Legacy Embers data must be migrated into the new system through a planned ETL process.
- Product requirements and architecture will be defined before application scaffolding begins.
- The GitHub repository is the durable source of truth for project documentation and code.
- ChatGPT is the primary workspace for product thinking, requirements, architecture, review, and project discussion.
- Codex and Google Antigravity may both be used as implementation engines against the same repository and specifications.
